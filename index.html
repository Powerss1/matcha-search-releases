Install in the way you prefer

The installer puts Matcha Search in your user folder, so it can update itself without administrator rights. The portable ZIP keeps everything in one folder; winget installs it for you.

Installer (recommended)

Download MatchaSearch-setup-x64-1.1.14.exe, run it, and launch from the Start menu. No admin prompt, per-user uninstall entry included.

Portable ZIP

Extract anywhere writable, run MatchaSearch.exe. The in-app updater works as long as the folder stays writable.

winget

winget install --id Powerss1.MatchaSearch -e
Manifest is being submitted to the winget community repository; until it lands, use the installer above.

Verify the download

The package is served from GitHub Releases. Comparing the hash takes ten seconds and proves the file on your disk is exactly what was published — even if a mirror or a proxy touched it.

PowerShell check

Run this in the folder that holds the download. The printed hash must match the one on this page. For the portable package, use MatchaSearch-win-x64-<version>.zip instead.

Get-FileHash .\MatchaSearch-setup-x64-1.1.14.exe -Algorithm SHA256 | Format-List

Hash matches

Run the installer, or extract the ZIP anywhere writable and run MatchaSearch.exe.

Hash does not match

Delete the file and download again from the official release page. Do not run it.

Keep the manifest

latest.json carries the version, URL, size and SHA-256 that the in-app updater checks before applying an update.

If Windows shows a warning

Matcha Search is currently published without a commercial code-signing certificate, so Windows SmartScreen shows “Windows protected your PC” the first time you run it. That message means “unknown publisher”, not “malware”. You can confirm the build yourself:

Check the hash first

Use the PowerShell command above. This is the check that actually proves the file is ours; the SmartScreen dialog cannot.

Open “More info”

In the blue dialog, click More info, confirm the file name is MatchaSearch-win-x64-…zip / MatchaSearch.exe, then choose Run anyway.

Next launches are quiet

SmartScreen only prompts on new, unknown files. Once it is on disk and matches the hash, normal launches start without the dialog.

What it does

Small surface, strong defaults. Everything below is on-device; the browser itself makes exactly one kind of background request — optional filter-list updates.

◈

Tracker shield

109k+ rules matched before a request leaves the browser, with per-site pause from the shield panel.

⌁

Encrypted DNS

DNS-over-HTTPS and HTTPS-only transport are enabled by default, with a clear toggle for each.

◐

Black & white

Two themes that recolor the window and every internal page with animated transitions.

⬡

Extensions library

Three bundled, on-device extensions plus a folder importer. No store, no remote install prompts.

⌘

Private windows

A separate profile with its own cookies and storage; extensions stay off in private mode.

↻

Signed updates

The updater reads latest.json, downloads over HTTPS and verifies SHA-256 before touching the install.
